# Semester for Android

Course timetable builder + focus mode + daily planner, fully on-device (no AI, no internet permission).

- **Website / browser demo:** https://krishnag1729.github.io/semester-app/
- **APK:** [latest release](https://github.com/Krishnag1729/semester-app/releases/latest) (Android 8.0+)
- **Build transcript (Claude Code):** https://krishnag1729.github.io/semester-app/transcript.html

This repository holds only the public website, the release APK and the transcript; the source code is in a private repository.
